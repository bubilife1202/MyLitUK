## Button Behaviors

### Save Prescription
```
- Downloads prescription as formatted text file or PDF
- OR: Saves to browser localStorage for "My Prescriptions" page
- File format: bibliotherapist-prescription-[date]-[emotion].txt
```

### Share
```
- Generates shareable image (Instagram/Twitter format)
- Contains: Quote + Author + "Prescribed by The Bibliotherapist"
- OR: Copies prescription URL to clipboard
- Optional: Pre-filled tweet/post text
```

### Another Dose
```
- Reloads with different random quote from same subcategory
- Smooth transition (fade out/in)
- Loading animation optional but recommended
```

### New Diagnosis
```
- Returns to Intro screen
- Clears current prescription from view
- Option to save current prescription before clearing
```

### Animations
```
Entry: Fade in sections sequentially (quote → notes → dosage → buttons)
Delays: 0.3s between each section
Quote: Typewriter effect optional (but CPU-intensive)
Buttons: Hover scale (1.05), active scale (0.95)
```

### Accessibility
```
- Ensure sufficient contrast (cream on charcoal passes WCAG AA)
- Keyboard navigation for all buttons
- Screen reader: Announce prescription sections clearly
- Skip to content option for repeat users
- Print-friendly CSS (remove dark background for printing)
```

### Mobile Responsive
```
- Stack buttons vertically on screens < 600px
- Reduce quote font size to 24px on mobile
- Collapse Dr. Pemberton's Notes into expandable section
- Maintain minimum touch target size (44px)
```
