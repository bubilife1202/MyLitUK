## Design Notes for Sub-Question Screen

### Visual Elements
```
- Same Dark Academia aesthetic as Intro
- Slightly dimmed background (focusing effect)
- Sub-category buttons:
  - Larger than Intro emotion tags
  - Left-aligned text for readability
  - Parenthetical asides in slightly smaller text
  - Subtle expand/contract animation on hover
```

### Transition Animation
```
From Intro to Sub-Question:
  - Fade out emotion tags
  - Slide in diagnostic text from left
  - Fade in sub-category buttons sequentially (0.1s delay each)
```

### Button Hover States
```
Default: Border + slight shadow
Hover: Border color intensifies + content preview (optional)
Click: Brief scale animation + immediate transition to Loading
```

### Mobile Considerations
```
- Stack sub-category buttons vertically
- Reduce parenthetical text size further if needed
- Consider collapsing Dr. Pemberton's commentary on very small screens
- Maintain touch-friendly button sizes (min 44px height)
```
